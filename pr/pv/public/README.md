# pr/pv/public

このディレクトリの中身は git 追跡対象外です（この README を除く）。
`bash pr/pv/scripts/prepare-assets.sh` をリポジトリルートで実行すると再生成されます。

原素材は `.temp/`（同じく追跡対象外）に置いてください。

## 手動で用意するもの

スクリプトでは生成できません。無い場合、映像は無音でレンダリングされます。

- `audio/narration/s01.wav` … `s09.wav` — シーン単位のナレーション音声
- `audio/bgm.mp3` — BGM

いずれも商用利用可のものを使い、クレジット条件を確認すること。

## グリッド用サムネイルの差し替え（S2）

`grid/` の画像は S2 の「増えていく動画」グリッドに敷き詰められます。
**このディレクトリは生成物です。直接置かず、`.temp/` に置いてください。**

差し替え手順:

1. `.temp/` に `S__*.jpg` という名前で写真を置く（LINE から書き出すとこの名前になります）。
2. `bash pr/pv/scripts/prepare-assets.sh` を実行する。
   `.temp/S__*.jpg` が順に `grid/frame-01.jpg` … へ変換され、
   最後に**冒頭の滑走映像から1枚**が自動で足されます。
3. 枚数が変わったら `src/script.ts` の `GRID_FRAME_COUNT` を実際の枚数に合わせる。
   スクリプトは実行のたびに実際の枚数を表示します。

推奨サイズは横 540px 以上。表示は 300×190 に切り抜かれるため、横長の絵が向きます。

48マスに対して枚数は少なくて構いません。`src/tiles.ts` がブロックごとに
決定的なシャッフルを配って敷き詰めるので、同じ絵が規則的に並ぶことはありません。

枚数と `GRID_FRAME_COUNT` が食い違うと、存在しない画像を読みに行ってレンダリングが
失敗します。黙って1枚欠けるより望ましい挙動です。
