# pr/pv/public

このディレクトリの中身は git 追跡対象外です（この README を除く）。
`bash pr/pv/scripts/prepare-assets.sh` をリポジトリルートで実行すると再生成されます。

原素材は `.temp/`（同じく追跡対象外）に置いてください。

## 手動で用意するもの

スクリプトでは生成できません。無い場合、映像は無音でレンダリングされます。

- `audio/narration/s01.wav` … `s09.wav` — シーン単位のナレーション音声
- `audio/bgm.mp3` — BGM

いずれも商用利用可のものを使い、クレジット条件を確認すること。

## グリッド用サムネイルの差し替え（S2）

`grid/` の画像は S2 の「増えていく動画」グリッドに敷き詰められます。
初期状態は滑走映像から自動抽出した仮置きですが、**任意の画像に差し替えられます。**

差し替え手順:

1. `grid/frame-01.jpg` から連番で置く。**01 始まり・ゼロ埋め2桁・欠番なし。**
2. 枚数を変えた場合は `src/script.ts` の `GRID_FRAME_COUNT` を実際の枚数に合わせる。
3. 推奨サイズは横 540px 程度。表示は 300×190 に切り抜かれるため、横長の絵が向く。

`prepare-assets.sh` は **既に `grid/` に画像があれば上書きしません**。
仮置きに戻したいときだけ `--regen-grid` を付けて実行してください。

枚数と `GRID_FRAME_COUNT` が食い違うと、存在しない画像を読みに行ってレンダリングが
失敗します（黙って1枚欠けるより望ましい挙動です）。スクリプトは実行のたびに
実際の枚数を表示します。
