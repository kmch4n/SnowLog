# 1.4.0 TestFlight 確認チェックリスト

App Store 版 1.3.0 から 1.4.0（TestFlight）へ更新し、実機で確認するための手順。
上から順に進めること。**§0 と §1 は必須**、それ以降は優先度順。

失敗を見つけたら、画面・手順・期待した結果・実際の結果・スクリーンショットを残す。
画面に `settings.xxx` のようなキー名がそのまま出ていたら、それも失敗として記録する（不要な文言キーを 93 件削除したため）。

---

## §0 インストール前（必須・1.3.0 のまま行う）

TestFlight 版は App Store 版の上にデータを保ったまま入る。起動時に一度だけ走る移行（保存方式の付与）は元に戻せないので、先に退避する。

- [ ] 設定 →「エクスポート」でバックアップ JSON を作り、「ファイル」アプリなど端末の外にも保存する（§6 で復元の確認にも使う）
- [ ] 次の数を控える: 動画の本数、お気に入りの本数、カスタムタグの数、日記の件数、統計タブの「滑走日数」と「動画」
- [ ] 設定 → カレンダーの「週始まり」と、ホームの並び順を控える

## §1 更新直後の起動（必須）

- [ ] TestFlight 版をインストールして起動する。「動画ライブラリの準備に失敗しました」という画面が**出ない**こと
- [ ] §0 で控えた数が一致すること（ホームの件数、お気に入りタブ、設定のタグ、カレンダーの日記、統計）
  - 統計タブは「今シーズン」を開く。シーズンは **10/1〜翌年 9/30**（#89 で変更）。過去の動画はシーズンのチップを切り替えて確認する。月別推移は 12 か月分並び、ヒートマップは横にスクロールできること
- [ ] サムネイルが以前どおり表示されること
- [ ] 動画を 3 本以上再生できること。可能なら、端末に実体がある動画と、iCloud にしかない（「iPhone のストレージを最適化」で退避された）古い動画の両方で試す
- [ ] アプリを完全に終了して再起動しても、上記が同じであること（移行は 1 回だけ走る）

## §2 動画詳細（今回いちばん手を入れた画面）

- [ ] 再生中にメモを入力し、1 秒以上待って自動保存させても、**再生が止まらない・頭に戻らない**こと
- [ ] 再生中にお気に入り・タグ・滑走種別・スキー場を変えても、再生が止まらないこと
- [ ] タイトルを入力して 1 秒以内に ★ を押しても、**入力したタイトルが消えずに保存される**こと（詳細を閉じて開き直して確認）
- [ ] タイトルかメモを入力して **1 秒以内に戻る**。開き直したとき、入力が保存されていること
- [ ] 入力中にカーソルが外れたり、画面が一瞬「読み込み中」に切り替わったりしないこと
- [ ] 「この動画の記録を削除」で削除でき、一覧から消えること

## §3 取り込み

- [ ] 1 本の取り込み（GPS 付きの動画なら、スキー場の候補が出ること）
- [ ] 一括取り込み（数本〜20 本）。完了後、ホームに結果のまとめが出ること
- [ ] iCloud にしかない動画の取り込み（ダウンロードを伴っても完了すること）
- [ ] 取り込んだ動画の再生、サムネイル表示、詳細での編集

## §4 ホーム・検索・カレンダー・統計

- [ ] 並び順メニュー（新しい順 / 古い順 / スキー場別）
- [ ] 長押しで選択モード → 一括お気に入り → 一括削除
- [ ] 左スワイプで削除
- [ ] 検索で文字を入力して、**すぐに**タグや期間（今月など）を押す。両方の条件が残ること
- [ ] カレンダーの月表示と週表示の切り替え、日付タップ、日記の追加・編集・削除
- [ ] 統計タブでシーズンを切り替えられること。「最近の動画」にタグが表示されること

## §5 設定

- [ ] 滑走種別の追加・削除・ドラッグでの並べ替え（並べ替えが画面を移動しても残ること）
- [ ] カスタムタグの追加と削除。削除したタグが動画から外れ、**スキーヤーのタグは影響を受けない**こと
- [ ] お気に入りスキー場の追加・削除
- [ ] 週始まりの変更がカレンダーに反映されること
- [ ] 重複候補の画面と、不要ファイルの削除が動くこと

## §6 バックアップ（1.4.0 で形式が v2 になった）

- [ ] エクスポートして共有シートで保存できること
- [ ] **設定を変えてから復元しても上書きされないこと**（1.4.0 で変更）: エクスポート → 週始まりを切り替える → いま作ったバックアップを復元 → 週始まりが**切り替えた後のまま**であること
- [ ] §0 で作った **1.3.0 のバックアップ（v1 形式）を復元**できること。既存の動画はすべてスキップ扱いになり、データが二重にならないこと
- [ ] 余裕があれば: 別の端末に TestFlight 版を入れ、バックアップを復元する。記録・タグ・日記は戻り、動画は「ファイル無し」として表示されること（動画本体はバックアップに入らない仕様）

アプリの削除と再インストールでの復元は、§0 のバックアップが端末の外に確実にある場合だけ行うこと。

## §8 #87 の修正確認（写真へのアクセス設定を変えるので最後に行う）

1. 設定 → SnowLog → 写真 →「選択した写真のみ」にし、動画を 1 本だけ許可する
2. 許可して**いない**、取り込み済みの動画を開く

- [ ] プレイヤーの位置に「写真ライブラリへのアクセスが必要です」と「設定を開く」が出て、「元の動画ファイルが見つかりません」には**ならない**こと
3. 許可していない別の動画を新しく取り込み、開く
- [ ] 同じ案内が出ること
4. 写真へのアクセスを「フルアクセス」に戻す
- [ ] 2 と 3 の動画を開き直すと、**再生できる**こと
- [ ] 前のビルドで「元の動画ファイルが見つかりません」になっていた動画も、開くと再生できるようになること
- [ ] 本当に写真アプリから削除した動画は、フルアクセスでも「元の動画ファイルが見つかりません」になること
