## §2 「選択した写真のみ」の範囲外の動画（#91、`286739c`）

準備: 設定 → SnowLog → 写真 →「選択した写真のみ」にし、動画を 1〜2 本だけ選んでおく。

- [ ] 単体インポートで、選んでいない動画を選ぶ →「この動画はインポートできません」が出ること。「設定を開く」で設定に移ること。ホームに何も増えないこと
- [ ] 単体インポートで、選んである動画を選ぶ → 今までどおりインポートでき、再生できること
- [ ] 一括インポートで、選んである動画と選んでいない動画を混ぜる → 選んである分だけインポートされ、ホームに戻ったときの結果に「アクセス範囲外: N本」が出ること
- [ ] 「フルアクセス」に戻し、さっき断られた動画をもう一度選ぶ → インポートでき、撮影日が正しいこと
- 補足: 範囲外の動画で `assetId` が返らない場合は、アプリ内コピーとして普通にインポートされ、再生もできる。その場合は「インポートできてしまった」ではなく、そのまま正常として記録する

## §5 2026-11-16 の不具合修正（監査で見つけたもの）

Web で確認できたものは Web でも確かめたが、ネイティブでの挙動は実機でしか分からない。

- [ ] **検索**: `IMG_` のように `_` を含むファイル名の一部で検索すると、その動画が出ること（以前は 0 件）。`100%` のような `%` を含む語も
- [ ] **統計**: 今シーズン（2026-27）の動画がまだ無い状態でも、シーズンのチップが出て、前のシーズンに切り替えられること。
  動画詳細を開いて統計に戻ったとき、スクロール位置が先頭に戻らないこと
- [ ] **動画詳細の自動保存**（#92 でフックに分けた）: タイトルとメモを入力して 1 秒以内に戻る → もう一度開くと残っていること。
  入力中に削除 → 削除されること。限定アクセスとフルアクセスで再生の表示が今までどおりであること
- [ ] **スキー場の入力**（動画詳細・日記・検索）: 候補をタップせず、マスターと完全に一致する名前（✓ が付く）を入力して欄を離れると保存されること。
  途中の文字で離れると保存済みの名前に戻ること。文字を全部消すと名前が消えること
- [ ] **単体インポート**: iCloud にしかない大きい動画を選び、読み込み中に「変更」で別の動画を選ぶ → 後から選んだ動画の撮影日・ファイルで保存されること
- [ ] **滑走種別**: 設定で既定の種別（例: ハーフパイプ）を削除 → アプリを再起動しても戻らないこと。
  その種別が付いていた動画の詳細に選択済みのチップとして出て、押すと外せること。新しい種別を追加すると一覧の末尾に入ること
- [ ] **重複候補**: 「大回り1」「小回り1」のように日本語で数字だけ同じ別の動画が、重複として出ないこと
- [ ] **ホームの一括操作**: 一括削除・一括お気に入りが今までどおり動くこと
- [ ] **英語表示**: 端末を英語にして、1 本の日・1 件の検索結果が "1 video" / "1 result" になること
- [ ] **権限の文言**: 新規インストールで写真の許可を求めるダイアログの説明に「再生」が入っていること
- [ ] **インポートのプレビュー**（#97）: 動画を選んだあと、灰色の枠ではなく動画の先頭のコマが出ること（シミュレータで確認済み）。
  修正前は実機でも灰色だった（ソースから確定。#97 のコメント）
