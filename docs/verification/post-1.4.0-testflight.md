## §2 「選択した写真のみ」の範囲外の動画（#91、`286739c`）

準備: 設定 → SnowLog → 写真 →「選択した写真のみ」にし、動画を 1〜2 本だけ選んでおく。

- [ ] 単体インポートで、選んでいない動画を選ぶ →「この動画はインポートできません」が出ること。「設定を開く」で設定に移ること。ホームに何も増えないこと
- [ ] 単体インポートで、選んである動画を選ぶ → 今までどおりインポートでき、再生できること
- [ ] 一括インポートで、選んである動画と選んでいない動画を混ぜる → 選んである分だけインポートされ、ホームに戻ったときの結果に「アクセス範囲外: N本」が出ること
- [ ] 「フルアクセス」に戻し、さっき断られた動画をもう一度選ぶ → インポートでき、撮影日が正しいこと
- 補足: 範囲外の動画で `assetId` が返らない場合は、アプリ内コピーとして普通にインポートされ、再生もできる。その場合は「インポートできてしまった」ではなく、そのまま正常として記録する
